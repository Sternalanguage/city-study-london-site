# 金融城研学社 · City Study London

交易方法与策略思路课程、伦敦与香港金融研修的官网。纯静态多页网站（HTML + CSS + 少量原生 JavaScript），无需构建，由 GitHub Pages 直接发布。

公开地址：https://sternalanguage.github.io/city-study-london-site/

- 中文 12 页：首页、课程与课表、伦敦十日研修、香港五日研修、关于我们、在线报名、四个免费公开课专题页等
- 英文版在 `/en/`
- 本站内容为交易方法与金融知识教育，不构成投资建议，不提供任何交易服务。交易可能亏损。
